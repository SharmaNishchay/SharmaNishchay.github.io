# Nischay Sharma's Portfolio

Welcome to my portfolio website! This site showcases my skills, experiences, and projects (coming soon). The goal is to provide a comprehensive overview of my work in software development, interface design, and narrative creation.

## Features

- **Intro Section**: Overview of my professional background and areas of expertise.
- **Responsive Design**: Optimized for both desktop and mobile viewing.
- **Dynamic Content**: Sections for about me, projects, skills, and contact details.
- **Custom Styling**: Unique design elements to highlight my personal brand.

## Technologies Used

- **HTML5**: Structure and content.
- **CSS3**: Styling and layout.
- **JavaScript**: Dynamic functionality.
- **GitHub Pages**: Hosting the website.

## Setup and Installation

1. **Clone the repository**:
    ```bash
    git clone https://github.com/sharmanishchay/portfolio.git
    ```
2. **Navigate to the project directory**:
    ```bash
    cd portfolio
    ```

## Usage

- Visit the live site: [sharmanishchay.me](https://sharmanishchay.me)
- Explore different sections to learn more about my work.
- Contact me via the form in the contact section.
